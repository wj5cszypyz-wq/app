# Store builder: build roadmap

Spec: `docs/superpowers/specs/2026-11-07-multi-niche-stores-design.md`

The build is split into phases that can run in separate sessions. Each phase gets its own detailed plan file,
written at the start of that phase against the code as it stands then (so it never plans against stale code).
Each phase ends with: all tests pass, `tsc` clean, `next build` passes, `npm audit` = 0, committed and pushed to
`claude/loving-fermi-42tguu`, and HANDOFF.md updated with what's done and what's next.
